# GWF Loan System（Gamble With Your Friends 借贷系统 mod）

> 当前版本 v0.2.1。
> 共识型房规 mod：**房间内所有人安装**，不修改任何游戏文件，不操纵任何赌博结果。
> 仅限你与朋友的私人房间使用，请勿分发或商用。

## 功能

- **平均分配**：房主开启时，把当前共享资金池 ÷ 房间人数，作为每人的「份额账户」与**单注上限**基准
- **单注硬拦截**：下注不能超过自己的份额余额（可由房主关闭）
- **玩家间借贷**：亏损后可向任意队友发起借款请求，对方**同意 / 拒绝**（带倒计时，超时自动拒绝）
- **自动还款**：借款人余额 ≥ **2 × 未偿债务总额**时自动触发，按房主设定的顺序逐笔还清：
  - 从小到大还 / 从大到小还 / 按借款顺序还
- **债务上限**（房主可设，0 = 不限）
- **团队贷款**（房主操作）：向「贷款公司」借一笔钱，立即进入团队资金池
  - 贷款额度、还款比例均由房主在「团队贷款」页签自行填写后生效
  - **多赚多还、少赚少还**：每局结算赢利 × 还款比例自动还贷，没赚不还
  - **还款期限**：下一回合结束之前；到期未还清 → 全员上车辆后**车辆倒计时不会开始**，
    同时每个玩家屏幕顶部常驻横幅「团队有一笔贷款未还完」
  - 防卡死兜底：还清贷款、达标当前对局金额、或当局回合计时耗尽后自动恢复正常流程
  - 房主可随时「立即还清」或「免除未还部分」
- **结算浮动详情**：每局结算后右上角弹出「借款详情」卡（全员可见）；F8 面板可随时查看完整借据
- **劝诫弹幕**：每次借款成功，借款人屏幕弹出一条劝诫弹幕（文案可在 config 扩展）
- **房主权威**：所有设置只有房主（Host）能改，其他人点击无效果
- **Mirror 全量快照同步**：Host 权威账本，每次结算/借贷/设置变更后广播，所有人看到一致状态
- **面板可用性**：打开 F8 面板时自动释放鼠标并锁定游戏输入，按钮可正常点击、点击不穿透到游戏世界

## 安装（三步）

```powershell
# 1. 编译（自动探测游戏目录，或传 -GameDir）
powershell -ExecutionPolicy Bypass -File build.ps1

# 2. 安装 BepInEx + 插件（只复制文件，不碰游戏原文件）
powershell -ExecutionPolicy Bypass -File install.ps1

# 3. Steam 正常启动游戏，进房后按 F8
```

从源码构建需要：
- .NET SDK（编译目标 net472，引用程序集走 NuGet 自动还原）
- 游戏已安装（默认自动探测 Steam 库；或设置环境变量 `GWF_GAME_DIR` 指向游戏根目录）
- `vendor\bepinex\BepInEx\core\` 下放置 BepInEx 5.4.23（win-x64）的 core dll
  （`BepInEx.dll`、`0Harmony.dll`，从 BepInEx 官方发布包复制；`install.ps1` 所需的
  `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 放 `vendor\bepinex\` 根目录）

只想直接游玩的朋友：到 Releases 下载 zip，解压到游戏根目录即可，无需编译。

卸载：`powershell -ExecutionPolicy Bypass -File uninstall.ps1`（只删除我们复制的文件）。

## 使用

1. **全员安装**本 mod（否则未安装者不会收到借贷消息）
2. 房主按 `F8` → 「房主设置」→ **开启并平均分配**
3. 玩家亏损后 `F8` → 「发起借款」→ 选债主 + 输入金额
4. 债主屏幕弹出同意弹窗
5. 每局结算后自动检查还款；右上角浮动卡 + 「借款详情」页签随时查看

## 技术说明

- BepInEx 5.4.23 外挂式注入（`winhttp.dll` + doorstop），**零修改**游戏目录任何原有文件
- Harmony 仅 patch 两个服务器端方法：
  - `MoneyManager.TryChangeBalance`（下注拦截，prefix）
  - `GameResultsManager.RegisterResult`（结算账本更新，postfix）
- 自定义 Mirror 消息（`NetworkServer/Client.RegisterHandler` + `SendToAll`）同步账本
- **v0.2.1 关键修复**：mod 程序集没有经过 Mirror weaver（weaver 只在游戏本体编译期注入），
  `Writer<T>.write` / `Reader<T>.read` 全为 null 时 Mirror 会**静默丢弃**每条消息——
  之前所有按钮（开启分配 / 借款 / 团队贷款）在单人开局和多人房间内都无效。
  现在插件启动时手工注册全部 8 类消息序列化器，并做序列化→反序列化往返自检（见启动日志）
- 房主端 UI 直接读权威账本（此前房主界面因忽略回环快照永远显示「未开启」）
- 本机日志：`<游戏目录>\BepInEx\LogOutput.log`（搜 `[Loan]`）

## 已知边界

- 游戏本体是**共享资金池**模型（全队一个钱包），本 mod 的「个人资金」是建立在结算数据上的份额账本：下注上限与借贷都基于该账本；共享池本身不受 mod 直接改动
- 若房主中途关闭 mod，未还借据会保留展示（标记为坏账视角），重新开启并分配时清空
